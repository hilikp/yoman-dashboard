# היומן של יחיאל

דשבורד פעילות יומית: משימות עבודה ואישיות עם סדרי עדיפויות, מיילים לטיפול, פגישות השבוע,
לוח חודשי/שבועי, רשימת קניות ופתקים.

עמוד HTML יחיד, בלי build, בלי תלויות, בלי שרת. הנתונים נשמרים ב-Gist **פרטי** בחשבון
הגיטהב שלך, עם עותק מקומי בדפדפן שממשיך לעבוד גם בלי אינטרנט.

---

## הרצה

```
start.bat
```

מריץ שרת מקומי על `http://localhost:8777` ופותח את הדפדפן. סגירת חלון הטרמינל מכבה אותו.
דורש Python (מותקן: 3.13).

> אין לפתוח את `index.html` בלחיצה כפולה. מכתובת `file://` הדפדפן חוסם את הקריאות ל-API
> של גיטהב, והסנכרון לא יעבוד.

---

## חיבור לגיטהב (פעם אחת לכל דפדפן)

1. פתח [יצירת Fine-grained token](https://github.com/settings/personal-access-tokens/new).
2. תחת **Account permissions** בחר **Gists: Read and write**. אל תסמן שום הרשאה נוספת.
3. קבע תוקף (מומלץ 90 יום), לחץ Generate והעתק את הטוקן.
4. הדבק אותו בשדה שבראש הדשבורד ולחץ "חיבור".

בפעם הראשונה הדשבורד יוצר בשבילך Gist פרטי בשם `yoman-data.json`. בכל מכשיר נוסף שתתחבר
בו עם טוקן, הוא יזהה את אותו Gist לבד וימשוך את הנתונים.

### מה קורה לטוקן

- נשמר ב-`localStorage` של הדפדפן הזה בלבד. לא נכתב לקובץ, לא נכנס ל-git, ולא מגיע לשום
  שרת מלבד `api.github.com`.
- ניתן למחוק אותו בכל רגע בכפתור "ניתוק" שבראש הדשבורד.
- ניתן לבטל אותו לגמרי מצד גיטהב ב-[Settings → Tokens](https://github.com/settings/tokens?type=beta).
- זו פשרה מודעת: טוקן שיושב בדפדפן. לכן ההרשאה מצומצמת ל-Gists בלבד, וכדאי לקבוע לו תוקף.

---

## איך הסנכרון עובד

- כל שינוי נשמר מיידית ב-`localStorage`, ונדחף ל-Gist אחרי כ-900ms של שקט.
- כשהלשונית חוזרת לפוקוס, ואחת לדקה, הדשבורד מושך את ה-Gist ומאמץ אותו אם הוא חדש יותר.
- הפתרון הוא last-writer-wins ברמת המסמך כולו. עריכה במקביל משני מכשירים באותה דקה עלולה
  לדרוס אחת את השנייה. לשימוש אישי זה בסדר גמור.
- הנקודה ליד הכותרת מציגה את המצב: ירוקה = נשמר בגיטהב, אדומה = מקומי בלבד או שגיאה.

## גיבוי

"ייצוא גיבוי" מוריד קובץ JSON עם הכל. "ייבוא גיבוי" טוען אותו חזרה ודורס את התוכן הנוכחי.
כדאי לייצא מדי פעם - Gist הוא לא גיבוי.

## מבנה הנתונים

קובץ אחד, `yoman-data.json`:

```json
{
  "version": 1,
  "savedAt": "2026-09-06T09:00:00.000Z",
  "items": [
    {
      "id": "i...",
      "title": "לחזור ללקוח",
      "notes": "",
      "domain": "work | personal",
      "kind": "task | email | meeting | shopping",
      "priority": "urgent | high | normal",
      "due": "YYYY-MM-DD",
      "time": "HH:MM",
      "from": "",
      "link": "",
      "done": false,
      "doneAt": "",
      "createdAt": "2026-09-06T09:00:00.000Z",
      "sample": false
    }
  ],
  "notes": [
    { "id": "i...", "text": "פתק", "color": "amber | mint | sky | rose", "createdAt": "..." }
```

`kind: "shopping"` לא נספר במונים שבראש העמוד ולא מופיע בלוח. הפתקים באוסף `notes` נפרד
ולא מושפעים משום פילטר.

## גישה מהנייד

הריפו ציבורי כדי ש-GitHub Pages יעבוד בחשבון חינמי. **הריפו מכיל קוד בלבד** - אפס נתונים
אישיים. הנתונים שלך יושבים ב-Gist פרטי מאחורי הטוקן שלך, ומי שיפתח את הכתובת בלי טוקן
יראה דשבורד ריק שמבקש התחברות.

### הפעלת Pages

1. בריפו: **Settings → Pages**.
2. תחת Source בחר **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`. שמור.
3. אחרי דקה-שתיים האתר עולה ב-`https://<המשתמש>.github.io/yoman-dashboard/`.

### התקנה כאפליקציה בטלפון

פתח את הכתובת בטלפון, התחבר עם הטוקן פעם אחת, ואז:

- **אנדרואיד (Chrome)**: תפריט ⋮ → Add to Home screen.
- **אייפון (Safari)**: שיתוף → הוספה למסך הבית.

הדשבורד נפתח במסך מלא בלי סרגל הדפדפן, בזכות `manifest.webmanifest`.

### התאמות לנייד

כפתורי הפעולה בשורות מוצגים תמיד במסכי מגע (במחשב הם מופיעים ב-hover), עיגול הסימון
מוגדל ל-26px, ושדות הקלט ב-16px כדי שאייפון לא יזום את העמוד בלחיצה על שדה.
